# Architecture Decision Records

Architecture decision records (ADRs) preserve why an important choice was made, not merely what the current code does. This prevents the project from repeatedly reopening settled questions without new evidence.

|---|---|

| [ADR 0002: Study interaction model](0002-study-interaction-model.md) | Accepted |

New records use the next four-digit number and include context, decision, consequences, and conditions that would justify reconsideration.
